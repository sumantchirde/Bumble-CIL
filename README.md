# Bumble Conversation Initiation Likelihood System

An AI Conversation Initiation Likelihood (CIL) scoring system that ranks profiles shown to female users so that profiles most likely to receive an opening message are surfaced first, supported by an AI First Message feature to facilitate ice-breakers.

In Bumble’s women-first design, only female users can send the first message to matches, and without initiation messages, matches expire in 24 hours. This creates two pain points: (1) the wrong profiles being shown first, and (2) the blank-message hesitation once the right profile is visible. The CIL system targets both.
